Focus Flow
Descripción

Focus Flow es una aplicación móvil desarrollada con Ionic, Angular y Capacitor que permite a los usuarios gestionar hábitos, tareas y estadísticas de productividad desde una única plataforma.

La aplicación busca ayudar a estudiantes, profesionales y emprendedores a mejorar su organización personal mediante el seguimiento de actividades diarias, el establecimiento de objetivos y la visualización del progreso alcanzado.

Características Principales

Autenticación

* Registro de usuarios.
* Inicio de sesión.
* Recuperación de contraseña.
* Cierre de sesión seguro.

Gestión de Hábitos

* Crear hábitos.
* Editar hábitos.
* Eliminar hábitos.
* Marcar hábitos como completados.
* Seguimiento de progreso.

Gestión de Tareas

* Crear tareas.
* Editar tareas.
* Eliminar tareas.
* Asignar prioridad.
* Marcar tareas como completadas.

Estadísticas

* Hábitos completados.
* Tareas completadas.
* Progreso general.
* Actividad semanal.
* Historial de actividades.

Perfil

* Edición de información personal.
* Configuración de preferencias.
* Gestión de notificaciones.
* Cambio de contraseña.


Tecnologías Utilizadas

Frontend

* Ionic Framework
* Angular
* TypeScript
* SCSS

Backend y Servicios

* Firebase Authentication
* LocalStorage

Aplicación Móvil

* Capacitor
* Android Studio

Arquitectura General

La aplicación está organizada mediante una arquitectura basada en componentes y páginas independientes:

* Home
* Login
* Registro
* Hábitos
* Tareas
* Estadísticas
* Perfil

Cada módulo gestiona su propia lógica de negocio y almacenamiento local.
